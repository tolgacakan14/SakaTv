# Şaka TV · HRP

Thomson Cast 150 (Google TV) için reklamsız, sade bir ana ekran: kurulu uygulamalar için dock, her açılışta beş film önerisi, kedim Şaka ve 30 dakika sonra açılan ekran koruyucu.

- Kurulum adımları: [KURULUM.md](KURULUM.md)
- Tek dosya halinde proje: `SakaTV.zip`
- Tanıtım sayfası: https://saka-tv.vercel.app

Film verileri TMDB API ve IMDb veri setlerinden gelir. This product uses the TMDB API but is not endorsed or certified by TMDB.
