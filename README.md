# Şaka TV · HRP

Thomson Cast 150 (Google TV) için reklamsız, sade bir ana ekran: kurulu uygulamalar için dönen galeri ve dock, her açılışta beş film ve dizi önerisi, kedim Şaka ve 30 dakika sonra açılan Şaka'lı ekran koruyucu.

- Kurulum ve güncelleme: [KURULUM.md](KURULUM.md)
- Her şey tek komutla: `./tools/tv.sh` (bağlanma, kurma, ana ekran yapma, durum, hata kaydı)
- Tek dosya halinde proje: `SakaTV.zip`
- Tanıtım sayfası: https://saka-tv.vercel.app

```
./tools/tv.sh baglan 192.168.1.107:PORT
./tools/tv.sh kur
./tools/tv.sh ana-ekran
```

Film verileri TMDB API ve IMDb veri setlerinden gelir. This product uses the TMDB API but is not endorsed or certified by TMDB.
